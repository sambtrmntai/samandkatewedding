# Invitation source PDFs

Three versions of the printed invitation, uploaded so the details can be pulled
into the site (which is currently full of `[PLACEHOLDER]` fields).

## Which is easiest to pull info from?

| File | Text layer? | Notes |
|------|-------------|-------|
| `invitations_searchable.pdf` | ✅ Yes (~2.8k chars) | **Easiest.** Selectable/searchable text — copy-paste or grep directly, no OCR needed. |
| `invitations.pdf` | ✅ Yes (~2.8k chars) | Identical text layer to the searchable version. |
| `invitations_basic.pdf` | ❌ None (image-only) | Scanned images only — needs OCR to read. Hardest. |

**Use `invitations_searchable.pdf`.** (Names in its text layer are OCR'd and a
bit garbled, but all the event details below came through cleanly.)
